# دستیار اینستاگرام (نسخه‌ی ارتقایافته)

پنل وب تک‌کاربره برای ساخت و انتشار خودکار محتوای اینستاگرام، آماده‌ی دیپلوی روی Railway.

## چه قابلیت‌هایی دارد

| بخش | کار |
|---|---|
| **ورود به پنل** | رمز (و اختیاری: ایمیل + رمز با `PANEL_EMAIL`) |
| **اتصال اینستاگرام** | نام کاربری و رمز، یا `sessionid` مرورگر؛ کد دومرحله‌ای/تأیید داخل پنل پرسیده می‌شود. رمز ذخیره نمی‌شود، فقط session |
| **استودیو** | موضوع (و عکس خودت یا تصویر AI) می‌دهی؛ کپشن + هشتگ + تصویر + ویس ساخته می‌شود |
| **انتشار** | پست، استوری (عکسی یا ویدیویی با ویس) و ریلز؛ فوری یا زمان‌بندی‌شده |
| **اتوپایلوت** | در ساعت‌های تعیین‌شده خودش موضوع انتخاب می‌کند، می‌سازد و یا منتشر می‌کند یا منتظر تأیید تو می‌ماند |
| **تنظیمات AI** | پنج بخش مستقل (چت دایرکت، کپشن، تصویر، **ویدیو**، ویس)؛ برای هر کدام شرکت، مدل و کلید جدا |
| **ویدیوی AI** | برای استوری و ریلز می‌توانی «ویدیوی AI» انتخاب کنی (deAPI): از روی متن، یا عکس خودت را زنده می‌کند؛ ویس هم رویش گذاشته می‌شود |
| **کشف و استوری** | موضوع می‌دهی؛ ریلز/پست‌های پربازدید همان موضوع را در اینستاگرام پیدا می‌کند و (با انتخاب تو یا خودکار) به‌صورت استیکر در استوری می‌گذارد |
| **کامنت خودکار** | پست‌های پربازدید/پرکامنت یک موضوع، پیج‌های مشخص یا لینک‌هایی که خودت می‌دهی؛ کامنتِ AI (با جهتی که می‌دهی) یا کامنت دست‌نویس تو، با تأیید دستی یا خودکار، همراه سقف و فاصله و توقف خودکار هنگام محدودیت |
| **دایرکت** | ربات پاسخ دایرکت با سبک نوشتن خودت (حالت پیش‌نویس یا خودکار) |

شرکت‌های پشتیبانی‌شده: OpenAI، Google Gemini، OpenRouter، Pollinations، deAPI (تصویر و ویدیو)، ElevenLabs (فقط ویس) و هر سرویس سازگار با OpenAI (Groq، DeepSeek، Together و ...) با «آدرس دلخواه». نام مدل‌ها قابل ویرایش است.

> **ویس:** اینستاگرام روی پست فید ویس ندارد. ویس داخل **استوری و ریلز** (ویدیو با صدای ساخته‌شده) قرار می‌گیرد.

## دیپلوی روی Railway

1. پوشه‌ی پروژه را در یک ریپوی GitHub (ترجیحاً private) بگذار.
2. در Railway: **New Project ← Deploy from GitHub repo**. فایل‌های `Dockerfile` و `railway.json` خودکار شناسایی می‌شوند.
3. **Volume** اضافه کن و آن را روی مسیر `/data` mount کن. بدون آن با هر دیپلوی session و پست‌ها پاک می‌شود.
4. در **Variables**:
   - `PANEL_PASSWORD` (الزامی، حداقل ۸ کاراکتر؛ رمز پنل و کلید رمزنگاری API keyها)
   - `PANEL_EMAIL` (اختیاری؛ اگر بگذاری ورود با ایمیل + رمز می‌شود)
   - `IG_PROXY` (اختیاری، مثال `http://user:pass@host:port`؛ برای وقتی اینستاگرام ورود از IP دیتاسنتر را رد می‌کند)
5. در **Settings ← Networking** روی **Generate Domain** بزن و آدرس را باز کن.

### راه‌اندازی اولیه (به همین ترتیب)
1. **تنظیمات AI:** موضوع و لحن پیج را بنویس، برای هر چهار بخش شرکت و کلید را بگذار و «تست اتصال» بزن.
2. **اتصال اینستاگرام:** با نام کاربری و رمز وارد شو. اگر چالش امنیتی آمد و حل نشد، `sessionid` را از مرورگری که در آن وارد instagram.com هستی کپی کن و از روش دوم استفاده کن.
3. **استودیو:** یک پست آزمایشی بساز و با «فقط بساز» بررسی کن، بعد منتشرش کن.
4. **اتوپایلوت:** اول روی «منتظر تأیید من بماند» بگذار و چند روز نتیجه را ببین.

## آپدیت نسخه‌ی در حال اجرا
فایل‌های جدید را روی گیت‌هاب آپلود کن (فایل‌های هم‌نام جایگزین می‌شوند) تا Railway خودکار دوباره دیپلوی کند. پست‌ها و تنظیمات قبلی حفظ می‌شوند (دیتابیس خودکار مهاجرت می‌کند).

## نکات مهم

- **ریسک حساب:** ورود با نام کاربری/رمز و انتشار خودکار از API غیررسمی اینستاگرام (کتابخانه‌ی instagrapi) خلاف قوانین اینستاگرام است و ممکن است حساب محدود یا بسته شود. پنل سقف انتشار روزانه، فاصله‌ی بین انتشارها و تأخیر تصادفی دارد و بهتر است با یک حساب غیرحیاتی یا با تأیید دستی شروع کنی. راه کم‌ریسک‌تر، API رسمی Meta (Graph API با حساب Business/Creator) است که می‌شود بعداً به‌جای این بخش گذاشت.
- **رمزنگاری کلیدها:** کلیدهای API با کلید مشتق از `PANEL_PASSWORD` رمزنگاری می‌شوند. اگر این رمز را عوض کنی، کلیدها خوانده نمی‌شوند و باید دوباره واردشان کنی.
- **پشتیبان‌گیری:** همه‌چیز در `/data` است (پست‌ها `panel.db`، تصویرها و ویدیوها `media/`، session اینستاگرام `ig_session.json`).
- **ریستارت وسط انتشار:** اگر سرور وسط ارسال به اینستاگرام ری‌استارت شود، آن پست «ناموفق» علامت می‌خورد و خودکار دوباره منتشر نمی‌شود (تا تکراری نشود)؛ پیجت را چک کن و در صورت نیاز دستی منتشر کن.
- **ساخت ویدیو** با ffmpeg است (در Dockerfile نصب می‌شود).

## تست

```bash
python3 tests/e2e.py
```
تست سرتاسری با سرور AI و deAPI جعلی، ffmpeg واقعی و instagrapi جعلی اجرا می‌شود (۱۱۹ بررسی).

## بخش‌های جدید

### ویس روی استوری/ریلز
ویس (از هر شرکت) اول به WAV استریو ۴۴.۱kHz با بلندی یکنواخت تبدیل می‌شود، با ۰.۴ ثانیه مکث روی تصویر قرار می‌گیرد و ویدیو با مشخصات استاندارد اینستاگرام ساخته می‌شود (H.264 High، ۱۰۸۰×۱۹۲۰، AAC استریو). فایل نهایی با ffprobe بررسی می‌شود و اگر مناسب نبود، علت دقیق در صفحه‌ی پست نوشته می‌شود. آپلود هم دیگر به moviepy وابسته نیست (در صورت خرابی moviepy از ffmpeg استفاده می‌شود).

### کشف و استوری (`/discover`)
- «جست‌وجوی دستی»: موضوع را بنویس تا فهرست پست/ریلزهای پربازدید با آمار نشان داده شود و با یک دکمه «استوری کن».
- «حالت خودکار»: در ساعت‌های تعیین‌شده برای هر موضوع جست‌وجو می‌کند؛ یا فقط فهرست می‌کند، یا بهترین‌ها را خودکار استوری می‌کند.
- پست «خوب» یعنی **هرکدام** از آستانه‌های بازدید/لایک/کامنت را داشته باشد و قدمتش از حد مجاز بیشتر نباشد.
- هر پست فقط یک بار استوری می‌شود؛ پست‌های خودت و پیج‌های مسدودشده کنار گذاشته می‌شوند.

### کامنت خودکار (`/comments`)
- منبع: موضوع/هشتگ‌ها (پست‌های پربازدید یا پرکامنت)، پیج‌های هدف، و لینک‌هایی که خودت می‌دهی.
- سبک: AI (با «جهت کامنت» که تو می‌نویسی)، دست‌نویس (کم‌استفاده‌ترین متن هر بار انتخاب می‌شود؛ `{author}` = نام صاحب پست)، یا ترکیبی. کامنت تکراری ساخته نمی‌شود.
- پیش‌فرض «نشانم بده، من تأیید می‌کنم»: هر کامنت پیشنهادی را می‌توانی ویرایش و تأیید کنی.
- محافظت از حساب: سقف روزانه (حداکثر ۴۰) و ساعتی، حداقل فاصله‌ی تصادفی، ساعت کاری، و توقف خودکار چند ساعته به‌محض اینکه اینستاگرام محدودیت بدهد.
- کامنت و استوری خودکار با API غیررسمی اینستاگرام خلاف قوانین آن است و ریسک محدود شدن حساب دارد؛ با عددهای کم شروع کن.

### تست
```bash
python3 tests/e2e_growth.py
```
بدون اینترنت و با instagrapi جعلی (tests/fakeig) و ffmpeg واقعی اجرا می‌شود (۴۳ بررسی).

## تغییرات این نسخه

- **رفع خطای `ClientNotFoundError … qe/expose/`** (کشف و استوری، ریلز): اینستاگرام این endpoint را حذف کرده ولی instagrapi هنوز هنگام ورود/ورود دوباره صدایش می‌زند. حالا ۴۰۴ این مسیرهای اختیاری نادیده گرفته می‌شود (`igcompat.patch_dead_endpoints`)؛ خطای مسیرهای دیگر مثل قبل نمایش داده می‌شود.
- **رفع خطای «قالب ویدیو مناسب نیست (h264/yuvj420p)»**: رنج رنگ ویدیو صریحاً به استاندارد (limited / BT.709) تبدیل می‌شود و اگر باز هم برچسب yuvj420p مانده بود، قبل از رد شدن خودکار اصلاح می‌شود.
- **استودیو**: کنار «عکس» و «ویدیو» تیک گذاشته شد؛ هرکدام روشن باشد همان ساخته می‌شود (هر دو = دو مورد جدا). ویدیو یا با deAPI ساخته می‌شود (اختیاری: عکس برای زنده شدن) یا ویدیوی خودت را آپلود می‌کنی (۹:۱۶ و استاندارد اینستاگرام می‌شود و صدای خودش حفظ می‌شود؛ حداکثر ۱۵۰ مگابایت). پست فقط عکس دارد.
- **اتوپایلوت**: حالت عادی = عکس (بدون حرکت و بدون تبدیل به ویدیو). فقط با روشن بودن «ساخت ویدیو با deAPI»، استوری و ریلز ویدیو می‌شوند. ریلز چون باید ویدیو باشد، در حالت عادی از عکس ثابت ساخته می‌شود. ویس برای استوری فقط وقتی ویدیوی AI روشن است اعمال می‌شود.

تست: `python3 tests/e2e_fixes.py` (۲۳ بررسی) و `python3 tests/e2e_growth.py` (۴۳ بررسی).

## نسخه‌ی جدید: منوی راست و فیلم بلند

- **منو**: در دسکتاپ منوی ثابت سمت راست؛ در موبایل نوار بالا با دکمه‌ی همبرگری (☰) که منو را از راست باز می‌کند.
- **اتوپایلوت ← طول فیلم** (برای استوری و ریلز):
  - **فیلم کوتاه**: همان حالت عادی قبلی.
  - **فیلم بلند (۲۰ یا ۳۰ ثانیه)**: AI یک کاراکتر ثابت و داستان پیوسته می‌نویسد، ۲ یا ۳ کلیپ ۱۰ ثانیه‌ای با صدا از deAPI می‌سازد (هر کلیپ از آخرین فریم کلیپ قبلی شروع می‌شود)، آن‌ها را به هم می‌چسباند و یک ویس واحد رویش می‌گذارد. این حالت خودبه‌خود ویدیوی deAPI را روشن می‌گیرد. روی «پست» اثری ندارد. اگر وسط ساخت خطا بشود، کلیپ‌های ساخته‌شده دوباره ساخته نمی‌شوند.
- تست: `python3 tests/e2e_long.py` (۲۴ بررسی).

## نسخه‌ی جدید: چند کلید deAPI، دایرکت سریع‌تر، تم اینستاگرامی

- **چند کلید deAPI** (تنظیمات AI ← ساخت ویدیو / ساخت تصویر با deAPI): در هر خط یک کلید بگذار. هنگام ساخت، کلیدها به ترتیب تست می‌شوند و با اولین کلید سالم کار انجام می‌شود. کلیدی که معلق/نامعتبر/بی‌اعتبار باشد (مثل `HTTP 403: Client account is suspended`) ۳۰ دقیقه کنار می‌رود و کلید بعدی استفاده می‌شود؛ اگر کلیدی وسط کار خراب شود هم همین کار انجام می‌شود. «تست اتصال» همه‌ی کلیدها را جدا گزارش می‌دهد. کلیدها رمزنگاری ذخیره می‌شوند و فقط ۴ نویسه‌ی آخر نشان داده می‌شود.
- **دایرکت**: بازه‌ی چک از ۵ تا ۶۰۰ ثانیه قابل تنظیم است (زیر ۲۰ ثانیه هشدار ریسک نشان داده می‌شود).
- **تم**: سفید و خاکستری ملایم شبیه اینستاگرام، دکمه‌ی آبی، گرادیان اینستاگرامی فقط روی لوگو و خط نازک بالای صفحه.
- تست: `python3 tests/e2e_keys.py` (۲۳ بررسی).
